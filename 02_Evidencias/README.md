# Entregables y evidencias por actividad

Esta carpeta permite localizar los productos esperados de las actividades del proyecto **PJtra001 — Conecta Joven: oportunidades para el empleo** y consultar sus respectivos Issues de GitHub.

La matriz es un instrumento de seguimiento: registrar un entregable como esperado no significa que ya esté elaborado, entregado o verificado. El estado debe actualizarse únicamente cuando exista información suficiente para respaldarlo.

> **Nota sobre el ejercicio académico:** San Gabriel es un municipio ficticio. Las actividades, registros o resultados simulados deben identificarse expresamente como simulados y no presentarse como hechos reales.

## Tablero de seguimiento del proyecto

Consulta el [tablero de GitHub Projects — PJtra001 Conecta Joven](https://github.com/users/YMUNOZF/projects/1/views/1) para revisar los estados, responsables, fechas y avances de las actividades.

Las definiciones de indicadores y sus valores ilustrativos se consolidan en la [Matriz central de indicadores](../03_Seguimiento/Matriz_Indicadores.md). La relación completa de actividades, dependencias y criterios de cierre está en la [Documentación consolidada de actividades](../03_Seguimiento/DOCUMENTACION_ACTIVIDADES.md).
