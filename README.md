# PJtra001_Ruta-de-empleabilidad-juvenil-para-j-venes-de-San-Gabriel
Ruta piloto de empleabilidad juvenil de 24 meses en San Gabriel, con atención diferenciada para jóvenes de 18 a 28 años, articulación institucional, acompañamiento laboral y evaluación de resultados para orientar su sostenibilidad y posible ampliación.
