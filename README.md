# PJtra001 — Conecta Joven: oportunidades para el empleo

## Propósito

El proyecto **Conecta Joven: oportunidades para el empleo** busca diseñar e implementar una ruta piloto de empleabilidad juvenil durante 24 meses, dirigida a jóvenes de 18 a 28 años. La ruta permitirá identificar y atender barreras de acceso al mercado laboral mediante orientación ocupacional, fortalecimiento de competencias y acompañamiento en la búsqueda de empleo. También promoverá la articulación entre la oferta institucional de formación y empleo, las necesidades de los jóvenes y los empleadores.

El seguimiento de la implementación permitirá valorar la pertinencia y viabilidad de la ruta, proponer mejoras y formular recomendaciones para su sostenibilidad y posible ampliación en el territorio.

> **Nota sobre el ejercicio académico:** San Gabriel es un municipio ficticio. Los resultados previstos no deben presentarse como resultados reales. Los registros y datos de ejemplo deben identificarse expresamente como simulados.

## Alcance

Implementar durante 24 meses una ruta piloto de empleabilidad para jóvenes de 18 a 28 años de San Gabriel, mediante orientación laboral, fortalecimiento de competencias, articulación con instituciones y empleadores, y seguimiento de resultados para evaluar su viabilidad y sostenibilidad.

## Gestión de actividades

Cada actividad se gestiona mediante un **Issue de GitHub**. El tablero de GitHub Projects permite consultar la vista consolidada de estados y fechas; el repositorio conserva los documentos y las evidencias de soporte.

Para consultar todas las actividades, revisa la [documentación consolidada de ACT-01 a ACT-11](03_Seguimiento/DOCUMENTACION_ACTIVIDADES.md) y la [matriz de entregables y evidencias](02_Evidencias/README.md).

### Criterio de cierre

El cierre de una actividad requiere verificar el entregable y contar con evidencia suficiente, vinculada desde el Issue o ubicada en la carpeta correspondiente. Cambiar el estado del Issue, por sí solo, no constituye evidencia de ejecución.

## Protección de datos y manejo de evidencias

No se deben publicar datos personales identificables ni información reservada. Las evidencias deben ser pertinentes para verificar el trabajo, contar con los permisos necesarios y almacenarse de manera que se proteja la información de los participantes. Antes de compartir el repositorio público, revisar los PDF y demás archivos para descartar datos personales, firmas, contactos privados o información no autorizada.

## Referencia de gestión

La documentación del repositorio describe la planificación y los criterios de verificación. No implica por sí misma que las actividades hayan sido ejecutadas o que los resultados esperados se hayan alcanzado.
